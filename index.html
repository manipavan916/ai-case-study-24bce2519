AI & Data Science Core Concepts Reference

A clear, beginner-friendly handbook explaining the key mathematical and statistical intuition behind every algorithm used in this application.

Linear Regression & R² Score

Linear Regression models the relationship between independent features \(X\) and continuous target \(y\) via \(y = \beta_0 + \sum \beta_i X_i\).

R² (Coefficient of Determination) = 1 - (SS_res / SS_tot). An R² of 0.85 means 85% of variance in the target is explained by the features!

K-Nearest Neighbors (KNN)

A non-parametric algorithm that classifies a new sample based on the majority vote of its \(K\) nearest data points in Euclidean space: \(d(p, q) = \sqrt{\sum (p_i - q_i)^2}\).

Rule of thumb: Scaling features (Standardization) is vital so features with large scales don't dominate the distance metric!

Decision Trees & Gini Impurity

Trees partition the feature space into rectangular regions by maximizing Information Gain. At each split, the algorithm selects the feature and threshold that minimizes Gini Impurity: \(1 - \sum p_i^2\).

Gini = 0.0 means a node is completely pure (all samples belong to one class).

K-Means Clustering & The Elbow Method

An unsupervised learning technique that groups unlabeled observations into \(K\) clusters. It alternates between assigning points to the nearest centroid and recomputing centroids.

The "Elbow" on the Inertia plot indicates the point of diminishing returns where adding more clusters no longer reduces variance significantly.

Precision, Recall & F1-Score

Accuracy can be misleading when classes are imbalanced. Precision measures \(\frac{TP}{TP + FP}\) (quality of positive calls), while Recall measures \(\frac{TP}{TP + FN}\) (coverage of actual positives).

F1-Score is the harmonic mean: \(2 \times \frac{Precision \times Recall}{Precision + Recall}\).
